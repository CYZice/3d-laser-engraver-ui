# 三维激光内雕 前端设计 PRD (Product Requirements Document)

## 1. 背景与目标 (Background & Goal)
**背景**: 这是一个基于Web的图像处理工具，旨在帮助用户将普通位图（JPG/PNG）转换为用于三维激光内雕的矢量点云数据（DXF）。
**目标**: 提供一个简单、直观的在线工具，使用户能够上传图片、进行基础编辑（裁剪/旋转），并最终获取转换后的DXF文件。
**核心价值**: 降低用户制作内雕数据的门槛，无需专业CAD软件即可完成从图片到加工文件的转换。

## 3. 详细功能需求 (Functional Requirements)

### 3.1 阶段一：待机与上传 (Idle & Upload)
*   **FR-1.1**: 页面中心显示拖拽上传区域 (Dropzone)。
*   **FR-1.2**: 支持点击上传和拖拽上传两种方式。
*   **FR-1.3**: **文件校验**:
    *   格式限制: `.jpg`, `.jpeg`, `.png`
    *   大小限制: <= 20MB
*   **FR-1.4**: 校验失败时，通过 Toast 或 Modal 提示具体错误信息（如“文件格式不支持”或“文件超过20MB”）。

### 3.2 阶段二：预处理/编辑 (Preprocessing)
*   **FR-2.1**: **图片预览**: 在画布中完整显示上传的图片。
*   **FR-2.2**: **裁剪功能**:
    *   提供可拖拽的矩形裁剪框。
    *   支持调整裁剪框的大小和位置。
*   **FR-2.3**: **旋转功能**:
    *   提供“左旋90°”和“右旋90°”按钮。
    *   旋转后，裁剪框应自动适配新的图片尺寸。
*   **FR-2.4**: **重置**: 恢复图片到初始上传状态（清除裁剪和旋转）。
*   **FR-2.5**: **确认转换**: 点击后将裁剪后的图片数据（Blob）提交至后端。

### 3.3 阶段三：处理与反馈 (Processing)
*   **FR-3.1**: **状态锁定**: 进入此阶段后，界面不可交互（显示遮罩或Loading），防止重复提交。
*   **FR-3.2**: **进度反馈**:
    *   通过轮询 (Polling) 接口获取后端任务状态。
    *   显示进度条 (0% -> 100%)。
    *   显示当前步骤文案 (e.g., "正在上传...", "正在计算点云...", "生成DXF中...")。
*   **FR-3.3**: **异常处理**:
    *   若后端返回 Error 状态，显示错误提示。
    *   提供“重试”按钮（返回编辑阶段或重新提交）。

### 3.4 阶段四：结果预览与交付 (Result)
*   **FR-4.1**: **结果展示**:
    *   MVP阶段: 显示后端生成的预览图 (SVG/PNG)。
    *   Phase 2 (规划中): WebGL 3D 预览。
*   **FR-4.2**: **对比模式**: 提供“原图/结果”切换开关或并排对比。
*   **FR-4.3**: **下载**: 点击按钮下载 `.dxf` 文件。
*   **FR-4.4**: **重来**: 点击“处理下一张”，清空当前状态，返回阶段一。

## 4. 验收标准 (Acceptance Criteria - Gherkin)

### AC-01: 文件上传校验
*   **Scenario**: 用户上传非图片文件
    *   **Given**: 用户位于首页上传区域
    *   **When**: 用户拖入一个 `.pdf` 文件
    *   **Then**: 系统应拒绝上传
    *   **And**: 显示错误提示 "仅支持 JPG/PNG 格式图片"

*   **Scenario**: 用户上传超大图片
    *   **Given**: 用户位于首页上传区域
    *   **When**: 用户选择一个 25MB 的 `.png` 文件
    *   **Then**: 系统应拒绝上传
    *   **And**: 显示错误提示 "文件大小不能超过 20MB"

### AC-02: 图片编辑
*   **Scenario**: 旋转图片
    *   **Given**: 用户已上传一张图片
    *   **When**: 用户点击“向右旋转”按钮
    *   **Then**: 图片应顺时针旋转90度
    *   **And**: 裁剪框应保持在图片可视范围内

### AC-03: 转换流程
*   **Scenario**: 正常转换流程
    *   **Given**: 用户已完成编辑并点击“确认转换”
    *   **When**: 后端任务状态从 `pending` 变为 `completed`
    *   **Then**: 进度条应达到 100%
    *   **And**: 页面自动跳转至结果预览页
    *   **And**: 显示“下载 DXF”按钮

### AC-04: 异常处理
*   **Scenario**: 网络中断或后端错误
    *   **Given**: 正在进行转换任务
    *   **When**: 轮询接口连续失败 3 次 或 后端返回 `status: failed`
    *   **Then**: 进度条变为红色或显示错误图标
    *   **And**: 显示具体的错误信息 (e.g., "服务器繁忙，请稍后重试")
    *   **And**: 显示“返回编辑”按钮

## 5. 范围界定 (Scope Boxing)

### In Scope (本次开发范围)
*   桌面端 Web 浏览器支持 (Chrome, Edge, Firefox, Safari)。
*   JPG/PNG 图片上传、裁剪、旋转。
*   异步任务轮询机制。
*   DXF 文件下载。
*   简单的结果预览 (SVG/静态图)。

### Out of Scope (不在本次范围)
*   **移动端适配**: 界面交互主要针对鼠标操作优化，不承诺完美支持触摸屏。
*   **3D 实时预览**: MVP 阶段不包含 Three.js/WebGL 的 DXF 渲染。
*   **用户账户系统**: 无需登录，即用即走。
*   **历史记录**: 不保存用户的历史转换记录，页面刷新后数据丢失。
*   **批量处理**: 仅支持单张图片串行处理。

## 6. 数据字段定义 (Data Definitions)

### 6.1 前端状态 (Redux/Zustand Store)
```typescript
interface AppState {
  step: 'UPLOAD' | 'EDIT' | 'PROCESSING' | 'RESULT';
  originalFile: File | null;      // 原始文件对象
  editorData: {
    rotation: number;             // 旋转角度 (0, 90, 180, 270)
    cropBox: { x, y, w, h };      // 裁剪区域 (相对于原图)
  };
  task: {
    id: string | null;            // 任务ID
    status: 'idle' | 'pending' | 'processing' | 'completed' | 'failed';
    progress: number;             // 0-100
    errorMsg?: string;            // 错误信息
  };
  result: {
    dxfUrl: string | null;        // DXF下载链接
    previewUrl: string | null;    // 预览图链接 (SVG/PNG)
  };
}
```

### 6.2 关键 API 接口
*   `POST /api/v1/image/convert`: 上传图片及编辑参数，启动任务。
*   `GET /api/v1/image/status/{taskId}`: 获取任务进度及结果链接。
